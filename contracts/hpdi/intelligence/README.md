# Intelligence contract

IntelligenceCapability accepts app-owned profile/version/input and derives trusted
context through HumanContext. Capability failures are classified; Service Desk
owns its existing DEGRADED response policy, while Room Request reports unavailable
AI with 503. Authentication and contract ambiguity fail closed. Private Python
triage uses the schemas at contracts/intelligence/v1 and a separate adapter
credential. Authorized Python search re-resolves Core citations before returning them.

Public Java API: `vn.haui.dx.hpdi.intelligence.api`. REST projections: [shared specification](../openapi.yaml). Existing error codes and visibility semantics are preserved.
