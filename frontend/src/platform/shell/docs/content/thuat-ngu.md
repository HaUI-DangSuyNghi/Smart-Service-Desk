| Thuật ngữ          | Giải thích                                                                  |
| ------------------ | --------------------------------------------------------------------------- |
| Workspace          | Không gian dữ liệu và phân quyền của một đơn vị                             |
| Ticket             | Một yêu cầu hỗ trợ sự cố CNTT                                               |
| Yêu cầu            | Bản ghi khởi tạo quy trình, có thể là ticket hoặc loại nghiệp vụ khác       |
| Công việc/nhiệm vụ | Một bước cần người thực hiện trong quy trình                                |
| Người giữ việc     | Tài khoản đang được giao nhiệm vụ cụ thể                                    |
| Tiếp nhận          | Kiểm tra dữ liệu trước khi chuyển sang quyết định duyệt                     |
| Ước tính — ET      | Thời gian làm dự kiến, thường tính bằng phút                                |
| SLA                | Mục tiêu thời gian bắt đầu và hoàn thành của lượt xử lý                     |
| Tải công việc      | Khối lượng xử lý ước tính còn lại theo chính sách phân công                 |
| Ticket gốc         | Ticket đại diện sự cố đã được điều phối viên xác minh để liên kết           |
| Ticket theo dõi    | Ticket được liên kết để theo dõi sự cố ở ticket gốc                         |
| Trích dẫn          | Liên kết từ câu trả lời AI tới đoạn tài liệu để đối chiếu                   |
| Preview            | Bản xem trước; trong kho tài liệu hiện là nội dung chữ trích xuất           |
| OCR                | Công nghệ nhận dạng chữ trong ảnh; chưa tích hợp vào luồng tải tài liệu này |
| Checksum           | Mã hỗ trợ kiểm tra nội dung file có thay đổi hay không                      |
| Request ID         | Mã tra soát một yêu cầu kỹ thuật khi cần xem log                            |
| Keycloak           | Thành phần đăng nhập và quản trị danh tính/phân quyền                       |
