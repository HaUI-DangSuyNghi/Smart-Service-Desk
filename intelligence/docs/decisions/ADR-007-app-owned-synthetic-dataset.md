# ADR-007: app-owned synthetic dataset expansion

Date: 2026-10-24. Engineering decision; independent owner review PENDING.

Preserve the 52-case v0.1 dataset byte for byte at SHA-256
`f3ba65dd318b2e06cce0e450faf7f2978916e8a6001c94270de38cb23fcb0c2e`.
Append 348 fictional cases to a separate v0.2 artifact: 400 cases, 30 categories,
six predefined axes, fixed seed 20261024. Root/case shape stays v0.1.0; new
curation metadata lives in a sidecar. Review/rights stay PENDING and HOLDOUT
NOT_LOCKED. No AI05 content, qrels, real tickets or owner signatures are borrowed.

Fact bank, templates, allocation and schemas belong to Tier 3 under the Service
Desk fixture directory. CLI/orchestration belongs to
`scripts/apps/servicedesk/ai06/`; domain-aware tests belong to
`intelligence/tests/apps/servicedesk/generation/`. Generic hdpi remains unchanged
and receives an injected runner through its public evaluation contract.

The generator has bounded attempts, stable UUIDv5 identities, exact UTF-8 hashes,
canonical LF JSON and explicit Unicode-preservation cases. Validators replay the
generator and check budgets, symbolic support, declared unsafe sources, exact and
near duplicates. Semantic mismatches and unsafe quotations remain visible even
when technical contracts pass; automated labels never become human gold.

Existing boundary gates remain required. Add a delta ownership gate anchored at
`1940b6eca68eca2509bef43280065412e33de42a` for new/changed shared scripts/tests,
full generic source scanning, actual built-wheel inspection and hostile mutation
proofs. Existing shared app-specific tools are historical scope, not a blanket
exception for new dependencies. No boundary debt entry is added or weakened.

Default CI is offline. A stable 30-case smoke sample is distinct from full
400-case cloud DEV evaluation. Cloud execution needs explicit egress opt-in,
provider/dataset/scope approval and budgets in addition to the existing governed
provider catalog. No approval is generated by this pipeline. Missing keys or
approvals produce BLOCKED/NOT_VERIFIED, never fabricated real API evidence.

Dataset engineering acceptance cannot authorize production or official quality.
Independent data/security review, reviewed labels and locked HOLDOUT remain open.
