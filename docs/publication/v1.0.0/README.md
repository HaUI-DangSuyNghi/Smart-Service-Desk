## Release assets and checksums

The release supplement consists of `frontend-production.cdx.json`,
`source-inputs.json`, `README.md` and `SHA256SUMS`, attached to the existing
[v1.0.0 release](https://github.com/HaUI-DangSuyNghi/Smart-Service-Desk/releases/tag/v1.0.0).
[SHA256SUMS](SHA256SUMS) covers the other three supplement files, not GitHub's
automatically generated source archives or application binaries.

Download all four files into one directory. Verify the exact downloaded bytes:

```powershell
$ErrorActionPreference = 'Stop'
Get-Content ./SHA256SUMS | ForEach-Object {
    $expected, $filename = $_ -split '  ', 2
    $actual = (Get-FileHash -LiteralPath (Join-Path $PWD $filename) -Algorithm SHA256).Hash
    if ($actual.ToLowerInvariant() -ne $expected) { throw "Checksum mismatch: $filename" }
    Write-Output "OK $filename"
}
```

## Reproduce from the tag

Use a clean detached checkout; Node/npm versions are recorded in source-inputs.json.

```powershell
git worktree add --detach ../ssd-v100-sbom v1.0.0
Set-Location ../ssd-v100-sbom/frontend
$sbom = npm.cmd sbom --package-lock-only --omit=dev --sbom-format=cyclonedx
if ($LASTEXITCODE -ne 0) { throw 'SBOM generation failed' }
[IO.File]::WriteAllText((Join-Path $env:TEMP 'ssd-v100-frontend.cdx.json'),
    ($sbom -join "`n") + "`n", [Text.UTF8Encoding]::new($false))
```

Fresh generation timestamps/serial numbers can differ. Compare component purls,
versions and dependency edges, and verify both input file hashes against
source-inputs.json; do not require a fresh SBOM to have the same file checksum.
